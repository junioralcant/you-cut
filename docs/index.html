Pipeline para creators e automação de clipes

Transforme vídeos longos em cortes prontos para publicar.

O YouCut recebe um vídeo longo, transcreve o áudio, identifica os melhores trechos, gera clipes verticais em 1080x1920, adiciona legendas embutidas e prepara metadados para acelerar sua distribuição.

O que o YouCut faz

A homepage foca no que interessa para divulgação: entrada, inteligência de recorte, acabamento visual e preparação para publicação.

Recebe vídeo de diferentes origens

Trabalha com URL do YouTube ou arquivo local, simplificando o início da pipeline para quem precisa testar, validar e iterar rápido.

Transcreve e entende o conteúdo

Usa Whisper para transcrição e uma etapa analítica para detectar trechos com maior potencial de virar cortes curtos e objetivos.

Entrega clipes já legendados

Gera vídeos verticais com legendas embutidas e opção de título no início, reduzindo a necessidade de edição manual depois do corte.

Exporta metadados úteis

Além do vídeo, o YouCut prepara título, descrição, hashtags e observações para publicação, agilizando o trabalho operacional do creator.

Suporta publicação automatizada

O fluxo pode seguir até a etapa de upload, com integração planejada para plataformas como YouTube, Instagram e TikTok.

Feito para velocidade operacional

A proposta do produto é tirar etapas manuais do caminho e transformar uma fonte longa de conteúdo em vários ativos curtos com menos atrito.

Como funciona

A pipeline foi desenhada para sair de uma única fonte de vídeo e chegar em múltiplos clipes curtos com apresentação final pronta.

01

Entrada

Recebe um vídeo do YouTube ou um arquivo já salvo localmente.

02

Transcrição e seleção

Converte fala em texto e identifica os melhores momentos do material.

03

Corte e acabamento

Gera clipes verticais, adiciona legendas e pode queimar o título nos primeiros segundos.

04

Exportação

Entrega vídeo final e metadados prontos para acelerar publicação e distribuição.

Workflow simples no terminal

youcut run "https://www.youtube.com/watch?v=exemplo"

youcut run "./meu-video.mp4" --clips 3

youcut run "./meu-video.mp4" --title-overlay

youcut run "./meu-video.mp4" --upload --platforms all

O que sai no final

Clipes verticais Arquivos em formato pronto para Shorts, Reels e TikTok.
Legendas embutidas Renderização final no vídeo para reduzir dependência de edição externa.
Arquivos de apoio Títulos, descrições, hashtags, ideia de thumbnail e justificativa de seleção.
